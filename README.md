# Personal Portfolio - Dablu Kumar

A premium, fully responsive personal portfolio website designed to showcase my projects, engineering background, and technical skillset. 

## 🚀 Key Features

* **Interactive CLI Terminal**: A functional, command-line interface emulator built in vanilla JS that allows visitors to query details using commands like `about`, `skills`, `projects`, and `contact`.
* **Dark / Light Theme Engine**: Premium theme switcher caching preferences via `localStorage`.
* **Active Contact Form**: Fully operational backend integration using FormSubmit AJAX to deliver messages directly to my inbox without page redirects.
* **Live Project Filtering**: Instant categorization of featured engineering systems (Frontend, Full-Stack, ML, Blockchain).

## 🛠️ Built With

* **Markup**: Semantic HTML5 (SEO friendly structure)
* **Styling**: Vanilla CSS3 (Custom grid, flexbox layout, and glassmorphism design tokens)
* **Logic**: Vanilla ES6 JavaScript (No heavy frameworks, optimization for fast load times)
* **Backend Services**: FormSubmit API for contact requests
